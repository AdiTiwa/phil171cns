# PHIL171CNS Computational Models!

This might come of use to anyone in the class who wants to play around with the more complex computational models that we talk about in class, while making sure that they aren't using a million pieces of paper :P

Using this might take a little bit of technical know-how, but I hope this guide helps you get around it. However, I'm too sleepy and also food-point poor enough that I don't have the coffee to write a guide to help you install python and git. Both of those have pretty nice installation informations, so go to [the python website](https://www.python.org/) and [the git foundation](https://git-scm.com/install/) to figure out how to install it for your computer.

Then follow these steps here!

1. Git clone this repository by running:
```bash
mkdir phil171
git clone https://github.com/AdiTiwa/phil171cns.git phil171
```

2. Chose what model of computation you want to mess around with (there's only one for now...) and change directory into that folder. Read the README.md for each type of model in that folder! The instructions from here vary, but it's not much more work left.
